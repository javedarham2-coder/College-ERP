# College ERP — Frontend Design

## 1. Scope
The frontend currently contains a login page prototype and an admission staff dashboard prototype.

## 2. Technology
- React
- Vite
- JavaScript
- CSS

## 3. Login Page
- College ERP branding
- Official college logo
- Email and password inputs
- Password visibility toggle
- Basic frontend input validation
- Light and dark theme support

## 4. Admission Dashboard
- Sidebar navigation for Overview, Applications, and Reports
- College logo in the sidebar
- Application summary cards
- Search by applicant name, ID, or course
- Application status filters
- Application review interface
- Demo approve and reject actions
- Theme toggle and sign-out

## 5. Current Limitations
- Authentication is not connected to a backend.
- Applicant records use hardcoded demo data.
- Application status changes are not persisted.
- Backend APIs are not connected.
- Student dashboard is not implemented.
- Frontend validation does not provide security by itself.

## 6. Next Steps
- Test the login and dashboard interfaces.
- Verify responsive layouts and theme switching.
- Agree on API contracts with the backend team.
- Integrate authentication and role-based access.
- Replace demo applicant data with backend responses.
- Test admission approval and student registration integration.
